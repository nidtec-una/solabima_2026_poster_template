# Plantilla Keynote - SOLABIMA 2026

Keynote no estaba instalado en la maquina donde se genero este
repositorio, por lo que no fue posible crear directamente un archivo
`.key` nativo (es un formato binario propietario de Apple sin
biblioteca de escritura confiable fuera de la propia app).

En su lugar, use el archivo PowerPoint ya preparado
(`../pptx/solabima2026_poster_template.pptx`), que Keynote importa de
forma nativa conservando el tamano de pagina (A0 vertical), colores,
logos y todos los bloques de texto editables:

1. Abra Keynote.
2. **Archivo > Abrir...** y seleccione
   `pptx/solabima2026_poster_template.pptx`.
3. Verifique que el tamano de diapositiva sea A0 vertical
   (841 x 1189 mm) en **Documento > Configuracion de diapositiva**.
4. **Archivo > Guardar como...** y elija el formato Keynote (`.key`)
   para obtener la version nativa.
5. Guarde tambien una copia como plantilla de Keynote
   (**Archivo > Guardar como plantilla...**) si desea reutilizarla
   para futuros posters.

Una vez guardado como `.key`, edite libremente el titulo, autores,
texto de cada bloque y reemplace los logos de marcador de posicion
en `../latex/logos/` (o los que se hayan importado) por los logos
oficiales cuando esten disponibles.
